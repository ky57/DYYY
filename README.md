### DYYY 

用于调整抖音 UI 的 Tweak  
仅在 **33.4.0 版本** 中测试。  
**最低系统版本：iOS 15.1**  
**仅供学习交流，禁止用于商业用途。**  

#### **功能说明**  
- 通过 **双指长按** 进入设置界面  
- 功能自测  

#### **系统版本适配（iOS 15.1）**  
- 编译目标与 deb 依赖对齐到 `firmware (>= 15.1)`  
- 合入上游「旧版 iOS 获取活动窗口」优化，兼容多 Scene / 过渡态  
- 相册权限适配 Limited / AddOnly（iOS 14+ API）  
- 设置页 PageSheet 使用系统 detents / grabber
